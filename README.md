# graphcast-pytorch

PyTorch implementation of [Graphcast](https://www.science.org/doi/10.1126/science.adi2336) (Lam et al., 2022), based on [the original code](https://github.com/google-deepmind/graphcast) and [the PyTorch implementation of MeshGraphNet](https://github.com/echowve/meshGraphNets_pytorch/tree/master)
